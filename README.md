# 🛡️ Fake Product Detection System

Ever bought something online and wondered if it's real or fake?  
This project helps answer that.

## What it does
- 📝 **Review Checker** — Uses AI to analyze product reviews and detect if they look suspicious or fake
- 📱 **QR Verification** — Every real product gets a unique QR code. Scan it to instantly know if the product is genuine.

## Why I built this
Counterfeit products are a huge problem in online shopping.  
This system combines Machine Learning + QR authentication to fight that.

## Tech Used
- Python, scikit-learn, NLP (for the AI part)
- Flask (to connect everything)
- HTML, CSS, JavaScript (for the website)
